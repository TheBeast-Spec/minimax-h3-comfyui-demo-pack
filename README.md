# MiniMax H3 Ref2VA ComfyUI Workflow

A blank workflow and a new four-reference example for testing character consistency, generated dialogue, and lip sync. This pack follows the reference structure of the Noncoder tutorial without sharing its original film images or script.

The new example has not yet been rendered and validated in ComfyUI.

## Start here

Download the repository as a ZIP using GitHub's **Code > Download ZIP**, then extract it. Import `MINIMAX_H3_REF2VA_WORKFLOW.json`, or keep using your existing copy. Follow [the demo setup guide](demo/README.md). The template remains blank; upload the images separately and paste the prompt.

This is an equivalent tutorial exercise, not an exact reproduction of the tutorial video. Its characters, wardrobe, car artwork, and dialogue are different. Results depend on installed versions, model selections, seed, settings, and generation variability.

## Source

Companion to Noncoder's **MiniMax H3 ComfyUI: Realism, Lip Sync & Latent Upscaling**. The adapted workflow follows the structure demonstrated in the [original workflow video](https://www.youtube.com/watch?v=ccvG-Z__pHk). See the [Comfy-Org MiniMax H3 model repository](https://huggingface.co/Comfy-Org/MiniMax-H3) for model files. Third-party nodes and weights have their own licenses.

## Contents and privacy

Includes a blank workflow, four newly generated fictional reference sheets, a fifteen-second dialogue prompt, setup instructions, generation provenance, and file checksums. It includes no original tutorial film images, reference recordings, model weights, credentials, or personal filesystem paths.
